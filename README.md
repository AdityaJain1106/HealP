# HealP

AI-Powered Digital Health Record & Medical Assistant

## Overview

HealP is a cloud-based healthcare platform designed to
centralize patient medical records and improve
doctor-patient collaboration through AI.

## Technology Stack

- React.js
- Vite
- Tailwind CSS
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Firebase Cloud Functions
- Google Gemini API
- Google Cloud Vision API
- Leaflet
- OpenStreetMap
- jsPDF

## Project Structure

- frontend/ - React application
- functions/ - Firebase Cloud Functions
- firebase/ - Firebase configuration
- docs/ - Project documentation
- tests/ - Testing resources
